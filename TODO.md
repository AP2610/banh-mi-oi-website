# Website owner checklist

This is the restaurant owners' checklist for launching and looking after the website. You do not need to change the website code.

## Before the website is announced

- [ ] Open `https://www.banhmioiparis.fr` and `https://banhmioiparis.fr`. Both should work without a security warning, and the second should send you to the first. Ask the site administrator for help if they do not. See [Domain and DNS](./docs/administration/domain-and-dns.md).
- [ ] Make sure the right people can sign in to Sanity, Netlify, Squarespace Domains, Resend, GitHub, and the restaurant email account. At least two trusted people should be able to recover the important accounts. See [Account handover](./docs/administration/README.md#account-handover).
- [ ] Review every page in French and English. Check the words, buttons, images, image descriptions, and links. See [Editing the website](./docs/owners/editing-content.md).
- [ ] Complete the address, opening times, telephone number, price range, Instagram address, and contact email in **Sanity → Site Settings**. See [SEO content checklist](./docs/owners/seo-content.md#fill-this-in-once).
- [ ] Complete the search title, search description, and sharing image for every page. See [SEO content checklist](./docs/owners/seo-content.md#fill-this-in-on-every-page).
- [ ] Check that the current menu PDF and menu images are correct in French. Add the English versions when they are ready. See [Menu Page](./docs/owners/editing-content.md#menu-page).
- [ ] Send a test message through the contact page and confirm it reaches the correct Gmail inbox. Ask the site administrator for help if it does not arrive. See [Contact-form email](./docs/administration/contact-email.md).
- [ ] Ask the site administrator to confirm that publishing in Sanity automatically starts a website update and that draft preview works. See [Sanity publishing webhook](./docs/administration/hosting.md#sanity-publishing-webhook) and [Previewing changes](./docs/owners/editing-content.md#previewing-changes).
- [ ] Add the website to Google Search Console, send Google the page list, and check the important pages. See [Google setup](./docs/owners/google.md#add-the-website-to-google-search-console).
- [ ] Claim or review the Google Business Profile and make its address, opening times, telephone number, website, and menu match the website. See [Google Business Profile](./docs/owners/google.md#google-business-profile).

## Whenever website content changes

- [ ] Preview the change in Sanity before publishing it. See [Previewing changes](./docs/owners/editing-content.md#previewing-changes).
- [ ] Fill in both French and English unless a field clearly says it is optional.
- [ ] Check buttons, links, and image descriptions before choosing **Publish**.
- [ ] Wait a few minutes after publishing, then check the change on the live French and English pages.
- [ ] Update the Google Business Profile too when the address, telephone number, opening times, menu, or website details change.

## Once a month

- [ ] Check that the live website, menu download, Instagram link, delivery links, and contact form still work.
- [ ] Open Google Search Console and check for warnings. See [Google regular checks](./docs/owners/google.md#regular-checks).
- [ ] Check that Google Maps shows the correct restaurant details and reply to reviews where appropriate.
- [ ] Check that the current opening times and menu are correct everywhere.
- [ ] Ask the site administrator to review failed website updates, account access, and service limits. See [Monthly checks](./docs/administration/README.md#monthly).

## If something goes wrong

Start with [Where to ask for help](./docs/owners/editing-content.md#where-to-ask-for-help). The [administration guides](./docs/administration/README.md) are for the person who looks after the website services.
