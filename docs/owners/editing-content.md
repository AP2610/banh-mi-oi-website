# Editing the website with Sanity

Sanity is where the restaurant team changes the words, images, links, and shared business information shown on the website.

Open:

```text
https://www.banhmioiparis.fr/studio
```

Sign in with the account invited to the Bánh Mì Oi! project.

## Important basics

- Fields marked as required must be completed before publishing.
- Most text has **FR** and **EN** boxes. Fill in both unless the field says it is optional.
- **Preview** shows saved changes before they are published.
- **Publish** starts an update of the live website. The update normally takes a few minutes.
- Do not create another copy of a page. Each page in the list is the one used by the website.

## Previewing changes

Open **Presentation** in Sanity to see the website beside the editing area.

1. Choose the page you want to check.
2. Make and save your changes. You do not need to publish them yet.
3. Use the page choices in Presentation to check the French and English versions.
4. Check the page at desktop and phone sizes.
5. When everything looks right, choose **Publish**.

The preview can show saved, unpublished work. Other website visitors cannot see that work. If the preview does not open, ask the site administrator to check the preview access settings.

## Pages

Open **Pages** to edit the four website pages.

### Homepage

Use this page to change:

- Hero title, subtitle, buttons, and main image
- Carousel title, subtitle, button, images, and image order
- Full-width image
- Our Story title, text, image, and optional contact button
- Order Now title, subtitle, image, Uber Eats link, and Deliveroo link
- Search and social-sharing information

Closed groups can be opened by selecting their title. They are closed only to keep the page tidy.

### Gallery Page

Use this page to change:

- Page title and subtitle
- Optional button
- Gallery images and their order
- French and English image descriptions
- Search and social-sharing information

### Menu Page

Use this page to change:

- Page title and subtitle
- Menu images and their order
- Main button
- PDF download button text
- Search and social-sharing information

The current French menu PDF must have the label `current-menu-fr` in the Media area. A future English PDF should have `current-menu-en`. If there is no English PDF, the website uses the French one.

### Contact Page

Use this page to change:

- Page title and optional subtitle
- Send button text
- Contact image
- Search and social-sharing information

The address, opening times, and receiving email are in **Site Settings**, not on this page.

## Navigation Menu

Open **Navigation Menu** to change the links inside the orange side menu.

For each link:

- Enter the French and English label.
- Choose where it should go.
- Drag links into the preferred order.

Only add links that visitors need.

## Site Settings

Open **Site Settings** to change information used in more than one place:

- Address
- Opening times shown on the website
- Opening hours supplied to search services
- Telephone number
- Price range
- Instagram address
- Email address that receives contact-form messages

Changing the receiving email changes where new contact messages are sent. Check it carefully.

## Images and files

Open **Media** to find uploaded images and files.

- Use clear, good-quality images.
- Avoid uploading the same file more than once.
- Give menu PDFs the correct label before publishing the Menu Page.
- When choosing several gallery or menu images, use the multi-image picker when it is available.
- Drag selected images to change their order.

Images selected directly on a page also ask for French and English descriptions. These descriptions help visitors who cannot see the image and help explain the page to search services.

## Publishing safely

1. Open the page or settings you want to change.
2. Make the change in French and English.
3. Check all warning marks.
4. Preview the text and links where possible.
5. Choose **Publish**.
6. Wait for the website update to finish, then check the live French and English pages.

If something is wrong, correct it in Sanity and publish again. Do not delete a page or create a replacement.

Publishing starts a new website update automatically. Several quick publishes may start several updates, so finish checking a document before publishing it where possible.

## Where to ask for help

Ask the site administrator when:

- a published change does not appear
- the website or Studio does not open
- an image or PDF cannot be selected
- the contact form stops sending messages
- a new page, section, language, or button destination is needed
