# Domain docs

## Before exploring

- Read `CONTEXT.md` at the repository root when it exists.
- Read relevant architectural decisions under `docs/adr/` when they exist.

## Vocabulary

Use the domain terms defined in `CONTEXT.md` in issues, tests, implementation plans, and architectural proposals. Do not introduce synonyms for terms the glossary defines explicitly.

## Architectural decisions
